2025년 의류 기준모델 WAPE 14.24%, 신경망 15.80%. 가방 기준모델 18.40%, 선택 혼합모델 18.77%, 신경망 24.64%입니다. 낮을수록 좋은 지표입니다.

상권별 업종 매출의 예측 실험이며 신규 브랜드의 매출이나 최적 스타일 비율을 예측하지 않습니다. 이미 확인한 2025년 결과는 탐색 평가입니다.

Modeling · 정확히 무엇을 학습했는가?

모델 한 문장 설명

26개 입력 → 32개 노드 → 16개 노드 → 매출 변화값 1개

NumPy로 구현한 다층 퍼셉트론(MLP) 회귀입니다. 은닉층은 ReLU, 출력은 선형입니다. LSTM·Transformer나 이미지 모델이 아닙니다. 의류·가방을 함께 학습하고 업종 표시를 입력으로 사용합니다.

학습 목표 = ln(목표 분기 매출 ÷ 전년 동분기 매출). 최종 예측 = 전년 동분기 매출 × exp(3개 시드의 출력 평균). 출력은 exp 전에 -10~10으로 제한합니다.

상권코드·이름·후보 선정 여부·split·실제 목표 매출은 입력 변수에서 제외했습니다. 숫자 변환 뒤 각 훈련폴드에서 결측 대체·평균·표준편차를 구하고, 같은 값을 해당 평가 자료에 적용합니다. 0에 가까운 표준편차는 1로 둡니다.

학습 설정

손실: 로그 매출비의 평균제곱오차(MSE). 가중치에 L2 기울기 항 0.001 적용. Full-batch Adam: 학습률 0.001, β1=0.9, β2=0.999, ε=1e-8.

시드 17·83·131, 100회와 250회 학습 비교. 조기 종료 없이 250회까지 학습하고 두 시점의 결과 저장. 입력 26개, 학습 파라미터 총 1,409개.

이 그래프는 훈련 손실입니다. 손실이 줄었다고 평가 성능이나 사업 성과가 좋아졌다는 뜻은 아닙니다.

매 분기 확장학습합니다. 목표 분기 t의 입력과 훈련 정답을 t-2까지로 제한했습니다. 2024로 설정을 선택하고 2025로 탐색 평가합니다. 2025 후반 평가에는 당시 이용 가능하다고 가정한 2025 앞 분기가 학습에 들어갑니다.

t-2는 공개 지연을 고려한 가정입니다. 실제 공개일·과거 개정본을 검증한 실시간 백테스트가 아닙니다. 이미 본 2025를 완전 독립 시험으로 부르지 않습니다.

비교모델과 후속 실험

  • 시차2기준: t-2 매출 그대로.
  • 전년동분기: t-4 매출 그대로.
  • 두기준평균: (t-2 매출 + t-4 매출) ÷ 2.
  • 신경망100·250: 위 MLP의 두 학습 횟수.
  • 후속 혼합 8개: 두기준평균 또는 시차2기준에 신경망100·250을 25% 또는 50% 혼합.
  • 후속 릿지 보정 6개: 업종별 매출 전용 또는 환경 추가 입력, 규제 강도 10·100·1000. 두기준평균 대비 상대 잔차를 가중 제곱오차로 학습. 예측 하한은 기준값의 1%.

전체 19개 모델을 업종별로 2024 WAPE 기준 선택합니다. 릿지·혼합도 기존 모델보다 좋다는 보장이 없습니다.

WAPE = Σ|예측−실제| ÷ Σ실제 ×100. MAE = 평균 |예측−실제| (억원). 중앙 APE = 개별 절대백분율오차의 중앙값. 편향 = (Σ예측÷Σ실제−1)×100.
